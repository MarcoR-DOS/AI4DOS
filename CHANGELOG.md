# Changelog

## 0.1.0-beta.1 (Unreleased)

- 16-bit DOS client for 8086/8088 systems, with mTCP networking, HMAC device
  authentication and Wire Protocol 0.3.
- English and German UI, CP437/CP850 support, transcripts, DOS 8.3 file saving,
  scrollback, reconnect and session resume.
- Python gateway supporting OpenAI, Anthropic, native Gemini, NVIDIA, Mistral,
  OpenRouter and OpenAI-compatible APIs.
- Self-hosting startup scripts, configuration templates and pinned Python dependencies.
